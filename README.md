# My Linux dotfiles

Personal configuration for Debian GNU/Linux.

## Managed configurations

- i3
- Alacritty with Catppuccin Mocha
- Polybar
- Picom
- Rofi
- Backgrounds
- Emacs

## Installation

Install GNU Stow, clone this repository into `~/dotfiles`,
then run `stow` for the packages you want to enable.

Review existing files and back them up before creating symlinks.
